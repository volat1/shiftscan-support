# ShiftScan Support Site

This repository contains the public help and privacy pages for ShiftScan, an iPhone app that reads work schedules and adds reviewed shifts to a calendar. The help page covers schedule scanning, date review, alarm permissions, and subscription management. Published support site: [volat1.github.io/shiftscan-support](https://volat1.github.io/shiftscan-support/).

- Help page: [index.html](index.html)
- Privacy policy: [privacy/index.html](privacy/index.html)

## Preview

The pages are static HTML and CSS; there is no package install or build command. Open `index.html` in a browser to preview the help page. The privacy policy is published under `/privacy/`.

## Maintenance

Keep product, subscription, and privacy statements consistent between the help and privacy pages. Check that `/privacy/` continues to resolve after file changes. Avoid adding examples that expose real employee schedules or personal information.
